# Onlia

> Onlia is a Canadian digital personal-lines insurance brokerage — the registered business name of Onlia Agency Inc., backed by Southampton Financial Inc. It sells auto, property and lifestyle insurance direct to consumers online and by phone, concentrated in Ontario, placing business with a panel of Canadian carriers rather than underwriting itself. Onlia publishes NO public developer portal, NO API documentation, and NO machine-readable API description of any kind: this file is generated by API Evangelist from the public site, not published by Onlia.

## API posture

- [No developer portal](https://www.onlia.ca/): developer., developers., docs. and api. under onlia.ca do not resolve; /developers, /developer, /api and /integrations on the marketing site return 404.
- [Consumer application](https://app.onlia.ca/): the only quote / bind / issue / self-service surface. An Angular single-page app on S3/CloudFront running a white-labelled Ignite Insurance policy administration platform. Its backing REST services are private to the app — undocumented, unversioned publicly, and not offered to third parties.
- [Partners](https://www.onlia.ca/partners): a B2B marketing page inviting affinity/group-discount partnerships by email. No API, SDK, sandbox, or technical onboarding.
- No OpenAPI, Swagger, AsyncAPI, GraphQL SDL, .proto, or public Postman collection exists. No ACORD, AL3, ACORD XML, NGDS or IVANS reference appears on the public site. No webhooks, no status page, no GitHub organization, no first-party SDK packages on npm, PyPI or any other registry.

## Regulatory context

- Canada has no open-insurance mandate, and Consumer-Driven Banking (Canada's open-banking framework) explicitly excludes insurance, so nothing compels Onlia to publish an API.
- Market conduct and broker licensing sit with provincial regulators (FSRA in Ontario); OSFI prudentially supervises the federally-regulated carriers behind Onlia's policies.
